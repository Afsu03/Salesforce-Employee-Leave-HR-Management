# SEHRM Frontend

This directory contains a React + Vite + TypeScript frontend scaffold for the Salesforce Employee Leave HR Management project.

Quick start (from repo root):

1. cd frontend
2. npm install
3. npm run dev

Notes:
- This is a UI scaffold with mock data and pages (Login, Dashboard, Employees, Request Leave, Approvals).
- I designed components to be easy to wire to your existing backend or Salesforce APIs — I will add API adapters in the next iteration.
